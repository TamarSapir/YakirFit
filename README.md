# Yakir fit – מדריך הקמה

האפליקציה מוכנה. נשאר לחבר אותה ל-Firebase (שירות חינמי של גוגל שמנהל את ההתחברות ושומר את הנתונים) ולהעלות אותה לאינטרנט. זה לוקח בערך חצי שעה, ועושים את זה פעם אחת.

עד שמחברים את Firebase, האפליקציה עובדת **במצב הדגמה**: אפשר לפתוח את `index.html` ולהיכנס כמשתמשי דוגמה. במצב הזה הנתונים נשמרים רק בדפדפן שפתח אותה.

---

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | האפליקציה עצמה |
| `app.js` | הקוד של האפליקציה |
| `config.js` | **כאן מדביקים את פרטי ה-Firebase ואת המייל של יקיר** |
| `firestore.rules` | כללי הפרטיות: מי רואה מה |
| `manifest.json`, `sw.js`, `icon-*.png` | מאפשרים להתקין את האפליקציה על מסך הבית בטלפון |
| `base.css`, `extra.css`, `build.py` | קבצי עבודה לעדכונים עתידיים. לא חובה להעלות אותם |

---

## שלב 1: פותחים פרויקט ב-Firebase

1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com) עם חשבון גוגל.
2. לוחצים **Create a project** (או Add project), קוראים לו `yakir-fit`. את Google Analytics אפשר לכבות.
3. במסך הפרויקט לוחצים על סמל ה-**Web** (`</>`), נותנים כינוי `Yakir fit` ולוחצים **Register app**. אין צורך לסמן Firebase Hosting.
4. יופיע קטע קוד עם `const firebaseConfig = { ... }`. משאירים את המסך פתוח, נצטרך אותו בשלב 4.

## שלב 2: מפעילים התחברות

1. בתפריט הצד: **Build ← Authentication ← Get started**.
2. בלשונית **Sign-in method** מפעילים:
   - **Email/Password** (רק האפשרות הראשונה, בלי Email link).
   - **Google**: מפעילים, בוחרים מייל לתמיכה ושומרים.

## שלב 3: מקימים את מסד הנתונים וכללי הפרטיות

1. בתפריט הצד: **Build ← Firestore Database ← Create database**.
2. מיקום: בוחרים אזור באירופה (למשל `eur3` או `europe-west`). מצב: **Production mode**.
3. אחרי שהמסד נוצר, עוברים ללשונית **Rules**.
4. מוחקים את כל מה שכתוב שם ומדביקים את כל התוכן של הקובץ `firestore.rules`.
5. **מחליפים את `yakir@example.com` במייל של יקיר** (המייל שאיתו הוא יתחבר).
6. לוחצים **Publish**.

## שלב 4: ממלאים את config.js

1. פותחים את `config.js` בכל עורך טקסט (גם פנקס רשימות מתאים).
2. מעתיקים את הערכים מהמסך של שלב 1 (`apiKey`, `authDomain`, `projectId` וכן הלאה) למקומות המתאימים. אם סגרתם את המסך, הערכים נמצאים ב-⚙️ **Project settings ← General ← Your apps**.
3. ב-`coachEmails` כותבים את **אותו מייל של יקיר** כמו בשלב 3.
4. שומרים.

## שלב 5: מעלים את האפליקציה לאינטרנט

הדרך הכי פשוטה היא Netlify, וגם היא חינמית:

1. נכנסים ל-[app.netlify.com/drop](https://app.netlify.com/drop) ונרשמים (אפשר עם חשבון גוגל).
2. גוררים את **כל התיקייה** `yakirfit` לחלון.
3. אחרי כמה שניות מתקבלת כתובת, למשל `https://shiny-name-123.netlify.app`. אפשר לשנות את השם ב-**Site configuration ← Change site name**, למשל `yakirfit.netlify.app`.
4. **חשוב:** חוזרים ל-Firebase: **Authentication ← Settings ← Authorized domains ← Add domain**, ומוסיפים את הכתובת בלי `https://` (למשל `yakirfit.netlify.app`). בלי השלב הזה הכניסה עם Google לא תעבוד.

כשמעדכנים קבצים בעתיד, גוררים שוב את התיקייה לאותו אתר בלשונית **Deploys**.

## שלב 6: מתחילים לעבוד

1. **יקיר** נכנס לכתובת, בוחר "הרשמה" ונרשם עם המייל שהוגדר. הוא נכנס ישר לצד המאמן.
2. בלשונית **עסק** הוא ממלא את **מספר הוואטסאפ שלו** ואת שעות העבודה. בלי המספר, למתאמנים לא יופיע כפתור "חידוש בוואטסאפ".
3. שולחים למתאמנים את הכתובת. כל מתאמן נרשם, ממלא שם וטלפון, ומחכה לאישור.
4. יקיר רואה את המתאמנים החדשים בלשונית **מתאמנים ← מחכים לאישור**, מגדיר כרטיסייה ומאשר.

### התקנה על הטלפון
- **אייפון (Safari):** כפתור השיתוף ← "הוספה למסך הבית".
- **אנדרואיד (Chrome):** תפריט ⋮ ← "התקנת האפליקציה" או "הוספה למסך הבית".

---

## מי רואה מה

| | יקיר | מתאמן |
|---|---|---|
| לו״ז של כל המתאמנים | ✓ | ✗ (רק האימונים שלו) |
| פרטים של מתאמנים אחרים | ✓ | ✗ |
| תוכנית אימונים | עורך | צופה בשלו |
| כרטיסייה ותשלום | עורך | צופה בשלו |
| בקשה לקביעת אימון | מאשר או דוחה | שולח |
| משקלים, מדדים, תמונות, תפריט | ✓ | ממלא את שלו |
| תמונת פרופיל | ✓ | מעלה לעצמו |

ההגנה הזו נאכפת בשרת של גוגל לפי `firestore.rules`, ולא רק במסך. גם מי שינסה לעקוף את האפליקציה לא יקבל מידע של מתאמן אחר.

---

## מגבלות שכדאי לדעת

- **תזכורת המים** קופצת כשהאפליקציה פתוחה. התראות לטלפון כשהאפליקציה סגורה דורשות שרת שליחה בתשלום (Firebase Blaze) ולא נכללו.
- **תמונות** נשמרות דחוסות בתוך מסד הנתונים, כדי להישאר בחבילה החינמית. החבילה החינמית מספיקה בקלות לעשרות מתאמנים.
- **שכחתי סיסמה** שולח מייל איפוס מ-Firebase. כדאי לבדוק גם בתיקיית הספאם.
- כדי להחליף מאמן או להוסיף מאמן נוסף, מעדכנים את המייל גם ב-`config.js` וגם ב-`firestore.rules`.
